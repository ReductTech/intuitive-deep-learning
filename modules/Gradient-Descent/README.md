# 禁区撤离 · 第 1 页

Guide: `/modules/gradient-descent`  
PPT: `/scenedeck/?deck=gradient-descent&slide=evacuation`

全屏 1600×900 游戏页。Three.js 渲染真实网格地形、三维建筑、枝叶、岩石、桥梁与直升机；摄像机跟随角色，窗口只显示大地图的一部分。地图背景不使用平面图片。

玩法是搜寻、交战、撤离：F 搜索容器，获得扫描器、医疗补给、方向探针和不同价值的核心。带出战利品才算收益，防护耗尽或三分钟风暴抵达则遗失背包。

按住小球向后拖拽蓄能，松手进行裂隙闪现。只显示近身方向和蓄能符文，不显示精确落点；过载闪现会发生方向与距离偏移。位移过程中消失，落地时生成门户、光环、碎屑、音效和短促震屏。沿途树木可被撞断，真实模型会倾倒并从实例批次中移除；守卫可被闪现撞杀。Q 或右键释放震荡，清除弹幕、破坏近处树木并击碎近处守卫。闪现、震荡、扫描共享以太，恢复和击杀回收让行动形成节奏。

守卫接近、蓄力并发射可躲避的弹丸，蓄力时显示攻击方向。搜索持续 1.35 秒，移动或受击会中断。E 消耗 12 以太扫描四秒，取得扫描器之前无法看见热力图。至少取得一枚核心后，在东北安全停机坪按 R 呼叫救援；新的守卫逼近，玩家需要守住八秒，直升机在后半段接近并接走角色。离开停机坪会中断撤离。方向键瞄准，空格释放已有蓄能或震荡，滚轮缩放。

地形、落点检测、扫描图、辐射表与方向探针共享 `model.ts` 的模拟场。自然素材采用按空间分区的 InstancedMesh；遮罩枝叶保留真实材质，实体建筑使用接触环境遮蔽；阴影限频更新以兼顾移动守卫、倒树和性能。

自然模型：[Quaternius Stylized Nature MegaKit Standard](https://quaternius.com/packs/stylizednaturemegakit.html)，CC0 1.0。工业模型：[Kenney City Kit Industrial](https://kenney.nl/assets/city-kit-industrial)，CC0 1.0。模型、依赖纹理、许可及来源记录位于模块签名 UUID 对应的 `assets/` 目录。冷却塔、废墟、管道钢架、地形、水面、桥梁与直升机在模块内建模。
