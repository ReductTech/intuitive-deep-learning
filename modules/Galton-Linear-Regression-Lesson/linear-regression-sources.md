# 线性回归与损失函数：来源说明

- Francis Galton, “Regression towards Mediocrity in Hereditary Stature,” *Journal of the Anthropological Institute*, vol. 15, 1886, pp. 246–263. 原论文档案：https://zenodo.org/records/1449548 。用于课程的历史问题、论文名称和 1886 年背景。
- UCL Special Collections, “Galton Papers” 与档案记录 GALTON/2/11/1/26：https://www.ucl.ac.uk/library/collections/ucl-digital-collections/special-collections-digital-collections/galton-papers 。用于核对论文档案背景；访问日期：2026-09-10。
- UCL Department of Statistical Science, “Our Early History”：https://www.ucl.ac.uk/mathematical-physical-sciences/statistics/department-information/our-early-history 。用于提示高尔顿统计贡献与优生学历史必须区分；访问日期：2026-09-10。
- 课程中的 14 个散点是为课堂观察重绘的教学示意样本，只保留“父母平均身高与成年子女身高正相关且存在离散”的结构，不是 Galton 原始数据的逐行转录。
- 页面中的 `ŷ = wx + b`、残差、MAE 与 MSE 是标准线性回归教学定义。所有图表均为模块内 SVG 生成，无远程运行时资源。
