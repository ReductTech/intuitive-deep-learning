# ResNet 的思想：不重写，只学修改量

按用户要求插在原第14与15页之间，成为第15页；原第15页保留并顺延。
上下对齐的普通网络与残差结构共享输入与目标，直接体现 H(x) 与 F(x) 的区别。
三个可逆步骤：比较学习对象、加入原输入、改稿比喻。没有自动播放或强制答题。
数字是标量中间表示的理想目标示例，不是分类概率、实测网络输出或现场训练。
使用整数十分位计算示例，避免 5.1−5.0 的浮点显示误差。
普通结构学习完整映射 H；残差分支学习 F，快捷路径提供 x，合成输出 x+F。
变更的是参数化/学习映射的方式，而不是替换最终任务标签或损失函数。
未加回输入时显示问号，强调仅有残差并不能得到最终输出。
改稿图以未修改的行和两处修改对应“原稿＋修改意见＝定稿”；只是类比。
不把残差称作预测误差，也不声称其幅度总小或小幅度必然保证易优化。
后续页面再讨论为什么接近恒等时这种结构有帮助，以及具体残差块。

依据：[He 等，Deep Residual Learning for Image Recognition，§3.1–3.2](https://arxiv.org/html/1512.03385v1)。
