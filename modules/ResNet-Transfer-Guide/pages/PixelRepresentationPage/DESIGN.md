# 第三页：从变化的像素到特征表示

## 教学目标

上一页解释图片由 RGB 数字组成；本页解释为何网络需要把这些数字加工成更适合分类的中间表示；下一页用卷积核对应相乘、求和与滑动演示特征图怎样算出来。

不要说“像素不能用于分类”。像素仍是网络输入，问题在于仅逐个比较原始像素容易受拍摄条件干扰。更稳定不等于完全不变；材质、轮廓等只是类别相关的视觉线索，也会受到光照、角度和遮挡影响。

## 布局与交互

固定在一张 1600 × 900 画布内，以两个手动阶段展开，不再展示差异热图或要求连续答题。

1. 上方四个 Shared Button：换角度、改光线、拉远距离、换背景。原始照片在左，变化照片在右；黄色框表示相同画面坐标，两边从实际显示的 ImageData 读取 RGB。可点击照片或用方向键移动坐标；画面坐标不代表固定的物理部位，某些坐标的RGB可能恰好不变。
2. 像素对照右侧只保留两行主结论“像素变了，仍是塑料瓶”和进入特征视图的按钮；初始及恢复原图后显示“换个拍法，类别会变吗？”，避免尚未操作就声称发生变化。照片与结论卡片底部对齐，同坐标取样说明放在照片下方；图片在可用空间内放大，不改变画布或字体体系。无完成锁或持久化答题。
3. 右侧复用 Shared Button 显示“看看模型学什么”和简洁右箭头，进入本页的原始像素 → 网络逐层加工 → 特征表示视图。不再重复展示眉题、分隔线、操作提示、拍摄条件解释与长段结论。按用户截图，删除像素对照视图正常状态下整行底部小字，包括缩放模拟、RGB来源和相同RGB的说明；仅加载中或加载失败时显示必要状态，模拟性质仍由照片标题中的“模拟”标识和本设计说明保留。照片、线索选择、表示定义形成三列；点击瓶口边缘、透明材质线索、弧形轮廓，SVG 高亮对应区域并联动解释与示意数字。
4. 特征视图右侧仅保留“特征表示”、一句定义和联动示意数字；删去步骤眉题、重复定义和长段说明。“特征表示”使用Shared h1字号和表示阶段的绿色，语义层级仍为h2；定义使用body字号及深蓝色，示意数字同步升为body字号。按用户要求，删除三列底部一排小字：照片下方概念示意、线索下方提示和数字下方真实性标注；不隐藏占位，三列不再预留说明行。人工高亮与示意数字的边界保留在画布/数字组的无障碍说明及本设计文档中。不改三列结构或Shared字号规则。有关稳定性不等于完全不变的限定保留在本设计说明中，不在页面反复陈述。
5. “再看像素”允许返回；展开后聚焦线索标题，返回后聚焦提问，Space 和 Enter 不触发播放器翻页。两个视图均删除底部长条结论，特征视图只保留返回操作，像素视图正常状态不渲染页脚。无跨页承接按钮，课程正常翻页不受影响。

## 来源与真实性

- 正面与 45° 角度使用本模块已有的瓶子图片。
- 光线为 RGB 乘以 0.56 的数字模拟，距离为缩放与重新取样，背景为人工轮廓遮罩下的背景替换；不是新增实拍，不演示真实光学过程。
- 同坐标 RGB 读取当前渲染数据，不写死数值。
- 绿色轮廓是人工标注的概念示意，不是分割模型或特征提取结果。
- 加工后的数值仅示意“表示仍是数字”，不是模型实测、类别概率或固定的可解释通道。
- 无新增依赖、无持续动画或后台计算；图片变换加载时计算一次，点击只更新采样和画布。

## 验收

类型检查；浏览器点击四种条件、采样、恢复原图、卡片内提问、三种线索与返回；检查键盘展开与焦点回返，确认没有跨页承接按钮；核对 RGB 来自照片画布；检查所有阶段和视窗中幻灯片子元素的边界与文本是否溢出。
