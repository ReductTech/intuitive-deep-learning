# 训练闭环：交互与教学约束

本页不设置开场选择题。进入页面即可点照片上的“开始前向”，把重点放在亲手推进训练的四个阶段与更新后复算。题目、答对解锁状态、重做判断入口及相关样式全部移除，不修改共享组件。首屏只显示上方五个前向模块，后续阶段只挂载当前需要的模块，释放空间放大对象。仍使用固定1600×900画布，布局按教学阶段切换，不按屏幕尺寸重排。

## 分步训练、查看总览与原位复算

1. 点照片“开始前向”：同一输入经过特征提取器 θ、临时特征 z、分类头 φ，产生预测概率。
2. 点预测“与标签比较”：隐藏前向五块，只展示预测结果与损失两个模块；以真实标签塑料瓶计算交叉熵损失。
3. 点损失“反向求梯度”：只展示原下排的损失、反向传播、优化器三个模块，沿右向左理解梯度返回；计算梯度，不改参数。
4. 点优化器“更新参数”：只展示特征提取器、分类头与优化器；θ、φ 改为绿色θ′、φ′，绿色分叉回写线指向两个参数目标。新特征与新预测尚未产生，因此此幕不展示它们。
5. 点优化器旁“查看总览”：恢复五个前向模块、下排三个模块与回写线。参数已更新，但保留旧特征、纸盒62%的预测和1.35的旧损失；这一步不算复算，不完成本页。
6. 在总览中的原照片上点“用新参数复算”：保持相同节点与布局，特征条和概率条原位过渡约1秒；此时才展示新特征、塑料瓶68%的新预测及0.39的新损失，完成本页。

前四次推进对应训练的四个阶段。查看总览与重新前向验证是两个独立操作，不增加第五、第六个训练阶段。点击立即切换状态，恢复旧版 180ms 的阶段高亮与淡入淡出、360ms 的特征条和参数滑点过渡，不再人为等待动画结束才能交互；当前只显示一个推进动作。已完成阶段可回到各自聚焦布局；进入总览后保留“查看总览”入口，四步导航全部标为已访问，不把总览误标为第五个训练阶段。“重看本轮”回到照片起点；过期推进、旧总览及重置前的阶段回调不能跳步。不设置跨页承接按钮。

## 数值与视觉

所有特征、流程与数值都是教学示意，非照片实测，不运行真实训练。更新前概率为 0.26 / 0.12 / 0.62，复算后为 0.68 / 0.12 / 0.20，均归一化；损失使用同一概率计算 −ln(p塑料瓶)，即约 1.35 → 0.39。为使前后变化直观，本例从预测纸盒 62% 改为预测塑料瓶 68%；分类分数示意条也同步改变排序。本例不代表一次更新就学会，实际单次更新不保证判对或损失下降；该边界保留在本设计说明中。按用户截图要求，删除页底整行“流程、特征与数值均为教学示意……”小字，当前步骤提示和训练交互保留。

前向两幕保留同一张照片与五块主线；其余幕卸载无关模块，最后的总览恢复原来两排完整结构。正向蓝色、标签比较琥珀色、梯度紫色、参数更新绿色，配合文字与箭头，而非只靠颜色区分。旧值保留浅色参考，新值以绿色叠加。箭头由 CSS 固定在网格间隙，随课件整体缩放；移除动态 SVG 光点、连线坐标测量、ResizeObserver 和动画计时器。

阶段4在两块参数卡与下方优化器之间的24px空隙显示绿色分叉回写线：从优化器顶端中心分路，分别指向特征提取器θ与分类头φ。复算前、后的总览阶段5/6均沿用原五列比例轨道的回写线；复算不再次改写参数。位置由与主节点相同的比例轨道确定，不测量 DOM、不覆盖内容、不引入循环动画；重播或回看更新前阶段时移除。

全部独立文字使用共享 Typography；在 1600 × 900 画布内检查起始状态及各步骤的边界、内部容纳和兄弟元素重叠。原生按钮支持键盘，局部空格或回车操作不触发播放器翻页，长按不连跳多个阶段，完成后焦点移到下一操作；减少动态效果时禁用所有过渡。无后台动画或待清理的计时器。总览必须先展示旧值，点击复算后才把旧值过渡到新值；保持旧浅色条作参照，减少动态效果时直接显示新值。

## 排版性能约束

2026-10-16 性能轨迹发现，主要开销不是脚本计算或绘制，而是多层 auto/minmax 网格和百分比高度图片相互依赖造成的昂贵排版。更新按钮并移动焦点时会同步触发多轮重排；单纯禁用动画无法消除。

纵向页面、正文和场景使用 Flex 分配剩余空间，仅保留横向节点网格；照片在已分配的容器内绝对定位并 object-fit: contain，不再以图片固有比例参与祖先网格的高度计算。程序切换焦点使用 preventScroll，避免额外滚动测量。不用隐藏溢出、删掉交互或全局播放器改动来掩盖问题。

性能回归需同时测试四步推进、查看总览、原位复算、阶段回看和重置，并保留浏览器排版轨迹及同条件点击到下一帧的对照测量。单次响应时间不得包含等待 CSS 过渡完全结束的时间。
