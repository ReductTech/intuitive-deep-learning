# 同页两幕：范围追踪与可计算的线索组合

第一幕维持回退版及连续关联带，不改网格、叠层顺序、定位和计算。第二幕改为可直接操作的多通道卷积小实验：改变前层线索或相对位置，让加权贡献、计算和后层响应同步变化；不再通过按钮切换预设瓶口轮廓。复用 Shared ContentBlock、Typography、Button、MathFormulaBlock 和提示条。

## 第一幕

连续 3×3 卷积，步长 1、不补边；7×7 输入产生 5×5、3×3、1×1 输出。输出索引为有效卷积的紧凑矩阵索引。receptiveField.ts 计算前层 3×3 邻域与输入并集，所有合法位置都不越界。

选择后同时高亮输入区域、前层邻域及后层格子，再揭示“感受野”。观察当前层后才能增加下一层，观察三层才开放组合一幕。不保留上一轮等大网格、蓝色内框或跳过第 1 层的流程。

## 保留连续关联带

两段半透明关联带连接输入范围右缘、前层邻域左右缘及所选输出格子的左缘。端点由同一卷积索引、实际网格尺寸和 4px 格间距计算，不沿用等大网格的固定坐标。关联带无指针事件，不遮挡按钮命中区域。

DependencyBands 只在挂载和尺寸变化时读取四个边界，通过渲染尺寸与逻辑尺寸之比消除外层等比例缩放的影响。ResizeObserver 在卸载时断开，无动画帧循环、计时器或持续测量。选中其他格子只重算区域，增加层后挂载新关联带。

## 第二幕：线索及相对位置共同影响响应

三个 5×5 前层通道分别仅含一个单位响应：上沿在 (1,2)，左弧在 (2,1)，右弧在 (2,3)，索引从 0 起。三个 3×3 示意核分别仅在 (0,1)、(1,0)、(1,2) 有权重 +1，其余系数均为 0；共享偏置为 −2，步长 1、无补边，计算全部 3×3 输出并逐元素 ReLU。左侧是三通道的空间叠图，不是 RGB 像素图，也不是模型实测激活。

- 初始只接入上沿、左弧，中心值为 0。右弧用 Shared 首次交互提示标出；点线索或底部主按钮均能接入它，中心值变成 1。
- 暂时移除一条，权重与位置保持不变，响应变成 0；接回后恢复 1。
- 保留三条线索，只交换左右弧所在位置。三张通道响应的总量没有减少，但原核在所需位置取不到左右弧：贡献由 1、1、1 变成 1、0、0，加入偏置后为 −1，经 ReLU 变成 0。虚线保留原位置供比较。
- 恢复相对位置，响应回到 1。默认引导为接入、移除、接回、错位、恢复；允许直接点击其他线索，状态机仍按实际前后变化记录观察，不按点击次数完成。
- 中央展示同一位置的各通道加权贡献，公式使用 Shared MathFormulaBlock，ReLU 可聚焦或悬浮解释。右侧所有数值来自真实计算，不手工指定显示结果；明确标注响应值不是类别概率。

本例权重和前层响应均为人工构造，不是训练结果；这个稀疏核只演示一种组合规则，并不表示所有 CNN 都必须集齐三条线索或按固定层数识别瓶口。卷积的局部跨通道加权与非线性机制参考 [Stanford CS231n](https://cs231n.github.io/convolutional-networks/)。更深增加后续组合机会，但不保证准确率。

组合状态保存在本页顶层 reducer 中，回看第一幕后返回不会丢失观察。重新观察同时恢复第一幕和组合实验。完成条件为三层范围均已观察，并亲手验证组合出现、移除线索后的变化、全线索错位后的变化、恢复位置后的响应；无额外选择题。

线索按钮支持键盘、触摸，移动位置时保持同一 DOM 节点。只有位置和色彩的有限短过渡，无计时器或持续动效，减少动态效果时关闭。

## 验证

固定 1600×900 比例布局；复用 Shared 的标题、文字、按钮、公式、提示。课程 CSS 不覆盖文字字号、字重或行高，不靠容器裁切隐藏溢出。验证第一幕文件／JSX保持不变，另对第二幕16种启用与位置组合的全部9个输出做独立计算核对；检查引导流程、自由操作、不可变状态、完成条件、回看、重置和键盘。类型／状态测试与实际截图、画布边界检查分别记录。
