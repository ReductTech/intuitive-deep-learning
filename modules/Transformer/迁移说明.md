# Transformer 模块迁移

将整个文件夹放入现有工程的 `modules/Transformer`，使用已有的 shared。

## 文件位置

- `assets`：14个当前图片/SVG，按七类整理；页码见“页面与素材清单.md”。
- `assetUrls.ts`：图片引用映射，无需再复制图片到 public。
- `models/glove-wiki-gigaword-50`：GloVe词向量模型。
- `backend/glove_service.py`：模型加载与查询接口示例。

## 前端入口

默认幻灯片播放器入口：`TransformerSceneDeckPage.tsx`，共34页。
引导式入口：`TransformerPage.tsx`；单页入口：`TransformerSlidePage.tsx`。
沿用 React、three、ml-pca、@icon-park/react 和现有共享组件配置。本包不含 shared、BERT 或 Python运行环境。

## 启动模型接口

在仓库根目录执行（macOS / Linux）：

```sh
python3 -m venv runtime_logs/transformer-glove-venv
runtime_logs/transformer-glove-venv/bin/python -m pip install -r modules/Transformer/backend/requirements.txt
runtime_logs/transformer-glove-venv/bin/python modules/Transformer/backend/glove_service.py
```

服务默认端口为59437；Vite 已将 `/api/glove` 单独代理到 `http://127.0.0.1:59437`，保留路径。可用 `IDL_GLOVE_API_URL` 覆盖目标地址；此接口不依赖 Cloud API。前端与该服务需要同时运行。
查询接口为 `POST /api/glove/embedding`。也可接入现有后端，参数和返回格式见服务源码。

现有工程可沿用原入口导入 `TransformerSceneDeckPage`。本包的 `upstreamCourseCatalog.ts` 仅屏蔽其他课程的目录依赖，不影响本课34页。
