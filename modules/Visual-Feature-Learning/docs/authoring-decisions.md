# 已确认的局部设计决定

## 参数更新与反向传播页面

以下记录来自此前用户反馈，适用于对应页面，不把不同方案中的局部选择视为所有页面必须同时满足的模板。以该页最近确认的方案为准。

- 连续对象动画方案：固定 loss 控制栏，输出与 GT 上移，逐格计算梯度，以卷积核作为缩放锚点，逐格更新后回到前向计算。
- 参数学习演示直接展示输入、参数、输出和目标，重复点击一次更新可观察参数变化与输出逼近目标；适合该方案的具体梯度与数值可放参数悬浮说明。
- 用户另明确要求的完整解释方案：同一界面直接展示梯度矩阵、计算来源、loss、反向传播与逐格更新，不用长段文字补救关系；正文和标签用 body，数字可用 bodySmall。
- 关注输入长度匹配的页面只比较长度，不展示无助于该判断的向量值与索引。

记录迁自 creator-skill 的个人偏好，仅保存局部决定，不代表本次重新验收。
