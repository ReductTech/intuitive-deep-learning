# 教学页面类型路由

本目录按页面承担的教学功能组织。这里的“面向未来”不是科技感视觉，而是：无论媒介、工具和交互方式如何变化，页面仍能用最短路径帮助学习者形成正确、可迁移的心智模型。

## 先定义理解增量

设计当前页前，先写清：

```text
进入本页前，学习者可能怎样理解
离开本页后，学习者具体多会看、解释或做什么
哪一条证据促成这个变化
最可能产生什么误解
是否必须通过交互才能获得这条证据
```

若“离开后”只能写成“了解了更多”，说明页面目标还不够清楚。

## 路由

| 当前页最主要的认知动作 | 读取 |
|---|---|
| 理解问题为何存在、为何值得学 | [context-and-opening.md](context-and-opening.md) |
| 从证据中发现模式并作出预测 | [observation-and-question.md](observation-and-question.md) |
| 建立概念、关系、符号与现象的对应 | [concept-explanation.md](concept-explanation.md) |
| 理解原因、过程、状态变化或推导 | [mechanism-and-process.md](mechanism-and-process.md) |
| 通过案例、对照或错误建立边界 | [example-and-comparison.md](example-and-comparison.md) |
| 提取、应用知识并依据反馈修正 | [practice-and-feedback.md](practice-and-feedback.md) |
| 压缩知识结构并迁移到新情境 | [summary-and-transfer.md](summary-and-transfer.md) |
| 确认位置、阶段、来源或下一步 | [structural-pages.md](structural-pages.md) |

按“学习者在本页完成的主要认知动作”选择一种类型。不要因页面同时含有图片、公式和问题就读取多个类型；这些只是表达媒介，不是页面目的。

## 所有类型共同追求

- 先给学习者能看见的对象或证据，再要求理解抽象语言；
- 使用学习者熟悉的语言起步，专业术语在真正需要时出现；
- 每种表达承担不同职责，图、文字、公式、声音和交互不重复朗读同一内容；
- 让学习者控制复杂内容的推进速度，并能回看、重试或复述；
- 不只依赖颜色、鼠标悬停、动画或声音传达关键意义；
- 真实材料可追溯，示意与生成内容明确标识；
- 不规定固定版式；每页从当前知识关系、证据和学习障碍独立生长。

始终同时遵守 [共同约束](../references/common.md) 与 [单页设计规则](../references/page-design.md)。
