# 设计学：信息结构与视觉表达

用于把知识关系转化为页面构图。先确定学生要完成的判断，再选择承载关系的对象和空间结构；不要先挑模板再往里填内容。

## 一个问题、一个视觉主角

每页围绕一个主要信息或核心问题，建立明确的视觉重点与阅读顺序。

- 只展示完成当前判断所需的信息。数值用于计算或比较时再呈现，不以数据量证明完整。
- 用少量大区域、明确空间关系和留白建立阅读顺序，避免等权重小卡片及 Dashboard 式堆叠。
- 按内容关系安排版式：比较的内容并排放，连续过程按顺序展开，对应信息靠近放，层级关系明确呈现。不强求每页同一种布局。
- 同页多个相关“块”仍放在一页，除非用户要求拆页；空间不足时精简非必要信息、调整比例，不裁切核心内容。
- 删除不参与理解和判断的重复文字、无关数值、装饰和控件，同时保留对象含义、必要条件、计算关系与观察目标。

## 连续表征与材料

同一对象在不同页面以及图片、图表、公式、代码和动画中保持名称、颜色、符号与位置关系对应。视觉编码要稳定；位置、长度、大小、颜色的变化必须与表达的量或状态相符。

历史、人物和经典实验优先使用真实材料，核实关键事实。难以获得适用素材时可教学重绘或生成插图；明确区分真实材料、模拟数据与示意表达，不将生成素材或重绘误称为历史原图、实测数据或真实计算结果。

素材来源、模型背景等必要资料可放讲稿或课程资料，不在学生页面堆放许可、访问日期等管理信息。

## 文字与实现

使用准确、清楚、自然的书面语言；标题直接提出问题、现象或结论。避免空泛口号、故作高深的术语和“这里先不讲什么”等元话语。用图和操作能说明的关系，不补成长段文字。

构图遵守主入口的固定画布与 Shared 约束；组件与样式用法见[工程实现](../engineering/implementation.md)。需要判断视觉取舍时读[美学](aesthetics.md)，设计操作时读[交互设计](interaction-design.md)。
