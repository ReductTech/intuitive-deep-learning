# Workflow A：参考改编

适用于用户提供既有 PPT，并要求转换、借鉴、修改或重新设计的任务。共用执行原则见[流程共用说明](common.md)。

**理解原稿 → 明确保留与调整范围 → 组织页面内容 → 设计页面 → React 实现 → 评估与修正**

1. **理解原稿**
   阅读可用的原稿与配套材料，识别其内容结构、页面顺序、核心信息、视觉特征和需要解决的问题。

2. **明确改编范围**
   判断用户希望忠实转换、局部修改、借鉴风格，还是整体重设计。明确哪些内容、页面和视觉元素必须保留，哪些可以调整。

3. **组织页面内容**
   建立原稿与新页面之间的对应关系。根据任务需要决定保留、拆分、合并、重排或新增页面。不得将整体重设计默认为可以随意改变原稿内容。

4. **设计页面**
   在满足内容要求的前提下，优化信息层级、页面构图、视觉表达和必要的交互。借鉴原稿不意味着必须复制其缺陷。

5. **React 实现**
   根据确定的设计和工程约束完成实现，优先复用适用的现有组件和基础设施。

6. **评估与修正**
   检查内容是否完整、原稿约束是否满足、页面是否正确呈现，以及交互和工程行为是否符合预期。

原稿处理方法见[参考与转换](../reference-conversion.md)，大纲维护见[大纲说明](../design/course-outline.md)，实现与验收分别见[工程实现](../implementation.md)和[评估说明](../eval/evaluation.md)。按当前阶段选读。
