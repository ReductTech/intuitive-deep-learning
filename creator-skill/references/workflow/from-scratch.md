# Workflow B：从零创作

适用于没有既有 PPT，需要从主题、目标、对话或其他材料开始组织演示的任务。共用执行原则见[流程共用说明](common.md)。

**理解目的与受众 → 组织叙事与大纲 → 确定视觉方向 → 设计页面 → React 实现 → 评估与修正**

1. **理解目的与材料**
   明确演示的用途、受众、核心目标、可用材料、演示时长及其他明确约束。只对会实质影响结果且无法合理推断的信息进行必要确认。

2. **组织叙事与大纲**
   确定演示要回答的核心问题、主要论点、证据和页面顺序。根据场景选择叙事结构，不套用固定的教学、科研或商业模板。

3. **确定视觉方向**
   根据受众、内容特征与演示目的选择适合的视觉语言、信息组织方式和页面表达形式。必要时比较不同方向。

4. **设计页面**
   将大纲转化为具体页面方案，明确每页的核心信息、内容层级、视觉主体及与前后页面的关系。

5. **React 实现**
   将设计转化为可运行的 React 页面，按实际需要加入图表、图片、动画、视频和交互。

6. **评估与修正**
   从内容、视觉、交互、工程实现及实际使用目的等维度检查结果，修复影响质量的问题并复验。

大纲维护见[大纲说明](../design/course-outline.md)，构图方法见[设计学](../design/design.md)，实现与验收分别见[工程实现](../engineering/implementation.md)和[评估说明](../eval/evaluation.md)。教学任务再按需读取[教育学](../design/pedagogy.md)。
