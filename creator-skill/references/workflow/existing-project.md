# 现有项目续作

适用于继续制作、修改、修复或优化已有 React PPT 项目、页面或模块的任务。共用执行原则见[流程共用说明](common.md)。

**检查现状 → 确定改动范围 → 从对应阶段继续 → 验证受影响内容**

1. **检查现状**：读取目标模块的大纲、相关页面和入口，了解已有成果、实现状态与工程约束；同时涉及既有 PPT 时，再核对原稿要求。
2. **确定改动范围**：区分内容调整、视觉重设计、交互修改或工程修复，保留已确认且不受影响的部分。
3. **从对应阶段继续**：沿用已有方向和授权，只补充本次需要的规划、设计或实现，不重新执行完整创作流程。
4. **验证受影响内容**：检查相关页面、状态和入口；涉及页序或共用逻辑时，扩大到实际受影响范围。

大纲修改见[大纲说明](../design/course-outline.md)，代码与布局修改见[工程实现](../implementation.md)，检查与复验见[评估说明](../eval/evaluation.md)。
