# PPT 知识空间与构图

设计或实现 1600×900 PPT 单页时读取本文件。先遵守 [common.md](common.md) 与 [page-design.md](page-design.md)。本文件提供空间语法，不提供可套用的页面模板。

## Stable Shell

课程级 Shell 可以稳定：画布、安全边距、标题基线、Typography 等级、语义色、页码和来源层。它帮助学习者保持方向感。内容舞台不因 Shell 稳定而固定为二栏、三栏、Hero 或卡片阵列。

## Knowledge Stage

标题与导航之外的核心区域是知识舞台。默认从无背景、无 Card、无 shadow、无固定 header/body 分割的连续空间开始，只在语义需要时增加容器。

先放置核心知识对象，再安排解释和控件。最大的对象应是最重要的证据，不是装饰、标题或通用容器。画面只允许一个真正的 Hero；其他元素必须支持它。

## Spatial Grammar

从知识关系选择空间关系，不从组件目录选择布局：

- **mapping / 一一映射**：实物与概念、生物结构与数学抽象保持可追踪对应；
- **comparison / 同参照对照**：两种方法、真实值与预测值共享尺度、坐标或评价条件，不做互不关联的卡片；
- **convergence / 汇聚**：多个输入、证据或现象指向一个判断、状态或抽象；
- **divergence / 分叉**：同一条件导致不同路径、类别或后果；
- **timeline / 时间变化**：保留前态痕迹并突出变化，不用页面替换抹掉比较依据；
- **trend / 趋势**：图表占据主区域，文字退到边缘并贴近所解释的变化；
- **local-detail / 局部放大**：主对象保持完整语境，局部机制通过连接明确的放大区解释；
- **state space / 状态空间**：把状态组合及相邻变化放进统一空间，而非罗列状态卡片；
- **hierarchy / 层级**：用包含、尺度和连接呈现整体—部分，不靠缩进文字代替结构；
- **input-output / 输入输出**：显示什么进入、什么被改变、什么保持不变、产生什么证据；
- **direct manipulation / 直接操纵**：操作发生在知识对象上，公式、图形和反馈同步变化。

可以组合两种语法，但必须有一个主导关系。若需要三种以上才能解释页面，通常说明认知任务尚未拆清。

## Attention Path

用三秒检查：第一眼落在哪里，第二眼去哪里，最终形成什么判断。若三个以上区域同时竞争，删减或重构。解释应贴近对象，来源和辅助信息降至最低视觉等级。

构图不能只靠均匀对齐。尺度差、重叠、连接、局部放大、共同坐标、前态痕迹和有用途的留白都可以表达关系，但颜色、位置和连线必须具有稳定含义。

## Fit

用比例区域和可收缩子项构图，遵守仓库的 PPT containment 约束。不要先做超大网页再靠自动缩放塞入画布。构图阶段就为标题、核心舞台、标签、来源和交互状态分配真实空间。
