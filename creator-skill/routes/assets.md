# 素材、来源与事实边界

素材只有在让学习者看见对象、条件、尺度或证据时才进入课件；气氛、装饰和“看起来像”不能替代论证。用户自带图片、数据和参考风格先保留其意图，再判断哪些信息可核实、哪些只是视觉线索。

区分来源事实、直接观测、教学重绘、生成图像、模型假设和设计推断。真实材料注明来源页、作者、许可与访问日期；生成、重绘、裁切、翻译和教学模拟注明性质。素材落在模块自己的 assets/ 与来源记录中，不依赖运行时远程地址；许可或事实不明时不要猜。

精确数字、坐标、公式、文字标签和可访问描述保留在 DOM、SVG 或专用渲染器中，不把关键事实封存在不可检索的位图里。找不到核心材料时说明限制，换成可核查的替代证据或明确标注的示意，不为凑数量堆素材。

历史、论文、档案或实验材料要让学习者能区分“当时看见的证据”“后来形成的解释”和“本课的复原”。需要历史叙事时再读 [historical](../visuals/historical.md)。
