# 完成后的检查

页面可运行后再看实际画面；用户直接要求评审时也从这里开始。PPT 的逻辑画布必须且只能是 1600×900 px；外层 viewport 可以缩放展示，但不得改变画布尺寸。等待字体和媒体稳定后查看完整 slide 截图；blog/Guide 逐项核对与 PPT 的页面顺序、页间问题、标题、公式、例子、结论和反馈含义一致。

重点看：学习者此刻要作出什么判断；证据是否可比、可回看且足以改变判断；图、词、公式是否指向同一对象；页间转场是否有认知理由；是否保留边界、反例和不确定性；内容是否完整可见。形式本身不判错，不要求填写评分表。

PPT 布局修改必须实际检查 .ng-ppt-slide-surface 的所有后代 bounding box，确认没有超出 surface；截图不能替代边界测量。覆盖会改变布局的展开或反馈状态。

有交互就试关键操作、键盘和适用的重置；确认流程提示、邻近解释和结果反馈各自使用正确的 UI Kit 语义并贴回原对象；有外部素材就核对显示、来源与示意标识。整套课程额外看前后页关联、事实/示意/假设区分、反事实或迁移，以及 blog/Guide 与 PPT 内容是否一致，不重新加载全部设计文档。

修正后复查受影响画面和状态。交付简述结果与未能验证的部分；工具不可用时如实说明，不声称检查通过。
