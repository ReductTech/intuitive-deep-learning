# 课程规划

从材料中抓住学习者的已有认识、主要障碍，以及最后应能解释或完成的事。缺少会改变事实或课程方向的信息时询问；其余作合理假设继续。

用“已有理解 → 新证据 → 新解释 → 应用”帮助组织内容，也可以采用更适合材料的路径。先找推动理解变化的证据，再决定页面顺序；页数服从用户要求和认知步骤，不套时长配额。

大纲写到足以指导设计即可：每页的主问题、关键证据、通往下一页的理由。用户说同页几个区块时保留在同页。只改一页时沿用已有上下文，无需重建课程规划。

课程视觉语言可以来自对象本身，如统计调查的记录、机器的数据流、生物的组织结构。确定跨页稳定的语义色和视觉线索，具体构图留给单页。无需为每门课程强造隐喻。

完整课程留出应用或迁移的机会，让学习者用新知识处理变化后的条件。交付已有大纲就够，不额外生成多份规划文档。
