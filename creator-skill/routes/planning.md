# 课程规划

从用户输入中提取学习对象、受众、已有直觉、主要障碍、可用证据、约束与交付范围；输入可以是主题、问题、材料、数据、图像、代码或参考风格。缺少会改变事实或课程方向的信息时询问，其余假设保持可回溯。

先写清“学习者要改变什么判断，以及什么证据会迫使它改变”，再安排页序。用认知动作组织路径：情境或旧模型 → 未决问题 → 观察/预测/操作 → 可比证据与中间因果 → 概念或形式化 → 反事实/应用/迁移 → 回扣开场与边界。可合并或省略环节，不套固定幕数、时长或页面类型。

大纲只写到足以指导 PPT：每页的主认知动作、关键证据、保留的前态、下一页为何必要，以及完成后能否在改变条件下调用。用户说同页几个区块时保留同一因果闭环；只改一页时沿用已有语义和视觉锚点。

视觉语言从对象和关系中生长，跨页稳定的颜色、坐标、符号和命名只为追踪同一对象服务；无需为课程强造隐喻。完整课程留出反例、边界或迁移机会，但不为了“互动”添加没有因果作用的操作。
