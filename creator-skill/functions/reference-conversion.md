# 既有课件的参考与转换

用于 PPT、截图、扫描页或现有 React 课件。先判断用户意图，不能仅因材料存在就机械复刻，也不能擅自把忠实转换改成重新创作。

## 确定保留范围

| 用户意图 | 默认处理 |
|---|---|
| 忠实转换、按原稿复刻、保持版式 | 保留指定的页序、版式、配色、图片和图表关系，只做必要的 React 与画布适配 |
| 参考、借鉴 | 提取核心知识、教学关系和局部视觉意图，在仓库 UI 体系内重新设计 |
| 重新设计、提升教学效果 | 可以重组叙事、版式和交互，先说明关键取舍，再确认方向 |
| 混合请求 | 按用户指定分别保留和重做，不推翻已认可的其他部分 |

意图未说明时，先检查材料并简述准备保留和调整的部分；只在不确定性会实质改变结果时澄清。沿用已有对话中的确认，不重复询问。

忠实转换不继承事实错误。发现错误、适配冲突或必须牺牲的原稿效果时明确说明，不能以“提高质量”为由自行重做整套排版。

## 检查材料

先了解页数、页面尺寸、主要内容、信息层级、视觉主角、图表关系和潜在交互。检查事实、公式、因果关系、图片质量、阅读顺序与画布容纳情况。

给出简短的“保留什么、调整什么、为什么”。材料较多时先建立总页序和转换范围，不因读完整套 PPT 就同时实现所有页。

参考图默认不覆盖 Shared UIKit、背景、字体、基础色彩和标题体系。标准页保留 ContentBlock 默认标题区；用户明确要求忠实保留原稿顶部或整体格式时，在指定范围内作为明确例外处理。

## 逐页推进

- 新建课程仍先确认转换大纲。忠实转换默认保留原页序；需要拆并页面时先说明理由，由已确认范围决定。
- 页数由材料范围、知识结构与学习节奏决定，不设固定配额。
- 每页先给简短说明与 ImageGen 设计示意图；已认可预览或明确跳过时不重复。设计确认前不写该页实现或生成正式素材。
- 默认实现一页、核对实际渲染、让用户检查后再继续；用户已授权连续制作时持续推进，每页仍独立检查，不到最后才发现整套布局问题。
- 对用户已认可页面的局部修复，直接按指定范围处理，不重新触发整套转换流程。

## 实现与能力选择

固定 1600×900、复用 Shared、根目录 UUID 资源路径与实际渲染验收仍适用，详细规则从主入口按需读取，不在本文件重复维护。

只有个性化解释、开放回答评价等需要语义能力时考虑大模型；只有训练、推理或较重计算明显受益时考虑模型服务。不为转换流程完整而接入 AI 或 GPU，也不自动启动外部服务或耗时训练。
