# 习题设计

习题是暴露理解、修正模型并继续学习的教学动作。先明确要学生识别、预测、计算、比较、解释、诊断还是迁移，再选题型；不为题型多样而平均分配。

## 通用判断

- 一题只测一个主要理解，答案来自课程已建立的证据或关系。
- 优先测理解和使用，不只要求复述定义或记住措辞。
- 干扰项来自真实误解；难度来自推理，不来自隐藏条件、绕口措辞或无关计算。
- 题目可放在概念前作预测，也可放在操作后作解释，不全部堆在课程末尾。
- 允许学生依据反馈重新观察、计算和尝试；答对也应进一步看清关系与边界。

## 题型与示例

### 选择题

适合区分、判断、预测、诊断与选择策略。正确项依据当前关系，错误项代表方向说反、忽略条件或过度泛化等典型误解。

例如，与其问“L2 Loss 的公式是什么”，可以给出两组误差 A=[1,1]、B=[0,2]，问“按误差平方和比较，哪个模型损失更大，为什么？”让学生判断大误差的影响。

选项长度、语气与格式不暗示答案；题干提供足够条件区分看似合理的选项。少用“以上都对/不对”，错误反馈针对所选误解，不统一显示“回答错误”。

### 填空题

适合计算、补全、变量对应或局部推导。空格落在有意义的推理节点，不随机挖去教材词语。

例如：“真实值 3，预测值 7，绝对误差=___，平方误差=___。”两个结果应成为后续比较的证据。

允许合理等价写法，如 `0.5` 与 `1/2`；多空属于同一推理链。答错先提示应检查哪一步，不急于公布答案。

### 简答题

适合解释、比较、因果推理、迁移或反思，尤其需要学生自己组织关系时。

例如：“为什么平方误差会放大特别大的预测误差？”比背诵两种损失的定义更能体现理解。

参考答案应有明确核心要点，允许不同表达，不要求固定术语；按正确、接近正确、错误区分理解，不做关键词匹配。明确错误指出冲突，遗漏则指出已理解与仍缺少的关系。

实现时复用 Shared Question，按主入口的“大模型调用”说明接入双入口与真实评阅，不新增一套题库登记或评分逻辑。

## 难度与反馈

逐步从原情境识别，推进到条件变化、图/公式/代码间转换、不同情境迁移，再到诊断旧错误模型或说明方法失效边界。后续练习不只换数字。

优先形成“学生回答 → 指出依据 → 显示证据 → 修正理解 → 再试一次”。反馈贴近刚操作的点、公式项或参数；能用图形、动画或反例揭示错误时，避免长篇解释。

加入前核对：答对能知道学生理解了什么；答错能判断可能错在哪里；移除这道题会损失一次有意义的学习机会。只能检查记住一句话的题目通常需要重设计。
