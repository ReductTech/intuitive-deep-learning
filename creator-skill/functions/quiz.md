# 习题设计

习题不是课程结束后的附加测试，而是帮助学习者暴露理解、修正模型并继续学习的教学动作。

选择题、填空题和简答题都应首先回答：

**这道题希望学习者做出什么认知动作？**

例如识别、预测、计算、比较、解释、诊断错误、判断边界或迁移，而不是先决定“这里放一道选择题”。

## 基本原则

- **一题只测一个主要理解。** 不要把多个互不相关的知识点塞进同一道题。
- **优先测理解和使用，而不是复述。** 能通过现象、数据、图形或新情境判断的内容，不直接问定义。
- **错误选项来自真实误解。** 干扰项应代表学习者可能形成的错误模型，而不是明显荒谬的陪衬答案。
- **题目提供足够证据。** 学习者应该能够根据已经看到、操作或推导过的内容作答，而不是猜教师意图。
- **难度来自推理，不来自绕口。** 不通过生僻措辞、隐藏条件、双重否定或无关计算人为增加难度。
- **答对后仍有价值。** 好题不仅判断是否正确，还让学习者进一步看清为什么成立以及什么时候不成立。
- **错误可以继续学习。** 反馈应指出错误对应的推理问题，并允许重新观察、计算或尝试。
- **尽量改变表面情境。** 后续练习不要只换数字，应适当改变表征、条件或应用场景，检查是否真正迁移。
- **习题位置服从学习过程。** 可以在概念出现前用于预测，也可以在操作后用于解释，不必全部堆在章节末尾。

## 选择题

选择题适合学习者需要在几个明确解释、策略或判断之间进行区分的情况。

高质量选择题通常包含一个明确问题和若干具有真实吸引力的错误模型。

例如不要问：

> L2 Loss 的公式是什么？

更适合问：

> 两个模型大部分样本误差接近，但模型 A 有一个特别大的误差。使用 L2 Loss 后，哪个模型更可能受到这个样本的明显影响？

设计时：

- 正确答案必须基于当前课程中的核心关系，而不是措辞线索。
- 干扰项优先来自常见误解、方向说反、忽略条件、混淆相邻概念或过度泛化。
- 不使用明显长度不同、语气不同或格式特殊的正确选项。
- 避免“以上都对”“以上都不对”，除非它们本身承担明确教学价值。
- 可以允许多个选项都“看起来有道理”，但题干必须提供足够条件使其中一个更合理。
- 学习者选错后，反馈应针对其选择对应的误解，而不是统一显示“回答错误”。

选择题最适合测：

**区分、判断、预测、诊断、选择策略。**

## 填空题

填空题适合答案边界明确，并且某个中间结果本身具有教学意义的情况。

适合填写：

- 一个计算结果
- 一个关键变量
- 一个符号
- 一个缺失步骤
- 一个具有明确含义的短语

例如：

> 真实值为 3，预测值为 7，L1 Loss = ___，L2 Loss = ___。

这类题有价值，因为两个结果的差异会直接成为下一步比较的证据。

避免：

> L2 Loss 又叫 ______ 损失。

这种题主要测试措辞记忆，通常不能说明真正理解。

设计时：

- 填空位置应该是推理链中的关键节点，而不是教材句子的随机挖空。
- 如果答案允许多种等价写法，不应强行使用字符串精确匹配。
- 数值题应允许合理的表示差异，例如 `0.5` 与 `1/2`。
- 一道题可以有多个连续空，但这些空最好属于同一条推理链。
- 学习者填错时优先提示其重新检查哪一步，而不是直接公布答案。

填空题最适合测：

**计算、补全、变量对应、局部推导。**

## 简答题

简答题适合答案不能被少量固定选项覆盖，并且学习者自己的解释方式本身能够体现理解程度的情况。

例如：

> 为什么 L2 Loss 会比 L1 Loss 更关注特别大的预测误差？

比：

> 请写出 L1 和 L2 的定义。

更能判断学习者是否理解两种损失的行为差异。

设计时：

- 问题必须有明确的核心判断标准，但允许不同语言表达。
- 参考答案写成若干核心要点，而不是唯一标准句子。
- 不要求学生使用特定术语，只要表达出的关系正确即可。
- 评价时区分“正确”“接近正确”“错误”，不要只做关键词匹配。
- 如果回答中存在明确的事实或方向错误，应指出具体冲突。
- 如果只是遗漏部分内容，应告诉学习者已经理解了什么，以及还缺哪一层关系。
- 简答题尽量要求解释原因、比较差异、预测变化或说明边界，而不是让学生背定义。

简答题最适合测：

**解释、比较、因果推理、策略表达、迁移和反思。**

## 题型选择

不要为了题型多样而强行平均分配。

当答案可以被少量典型理解状态覆盖时，用选择题。

当需要一个明确的中间结果时，用填空题。

当真正重要的是学习者如何组织关系和解释原因时，用简答题。

如果一道题既可以做成选择题又可以做成简答题，先问：

**我更想知道学生能不能识别正确关系，还是能不能自己生成这个关系？**

前者用选择题，后者用简答题。

## 难度设计

高水平习题的难度主要来自认知距离，而不是题目表面复杂度。

可以依次提高：

1. 在原情境中识别刚学过的关系。
2. 改变数字或局部条件后重新判断。
3. 改变表征，例如从图转到公式，从公式转到代码。
4. 改变情境但保留同一知识结构。
5. 加入一个容易诱发旧错误模型的条件。
6. 要求解释为什么某个方法在这里失效。

不要用增加无关文字、繁琐计算或模糊措辞制造“难题”。

## 反馈

反馈本身也是课程内容。

优先形成：

`学生回答 → 指出其依据 → 显示结果或证据 → 修正理解 → 再试一次`

而不是：

`学生回答 → 正确 / 错误 → 下一题`

反馈应尽量贴近当前被判断的对象，例如图中的点、公式中的项、模型中的参数或学生刚刚选择的解释。

能通过操作、动画、图形变化或反例让学习者自己看到错误时，优先使用这些证据，不用长篇文字解释。

## 最低质量标准

一道题在加入课程前，至少确认：

- 学生答对后，我们能知道他理解了什么。
- 学生答错后，我们能大致知道他可能错在哪里。
- 题目答案来自课程中已经建立的证据或关系。
- 去掉这道题后，会损失一次有意义的理解检查或学习机会。

如果只能判断“学生记没记住一句话”，而不能帮助判断其知识模型，这道题通常还需要重新设计。
