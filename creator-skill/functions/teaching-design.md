# 教学设计

用于新课程、开场、页面构图和交互方案。以下是设计取向，不要求每页同时使用全部方法。

## 学习如何发生

- **渐进披露**：一次主要引入一个新变量、关系或任务，避免第一屏同时讲背景、概念、方法和结论。
- **先体验后抽象**：从熟悉对象、现象与操作进入，再建立术语、公式和代码。
- **直接操纵**：让学生操作知识对象本身，例如拖动数轴上的分类边界，而非另设脱离图形的控件。
- **认知冲突**：先形成预测，再用结果或反例推动修正；反馈提供证据，不只显示正确或错误。
- **支架渐隐与安全失败**：开始提供必要提示和有限自由度，理解后逐步解锁；允许撤销、重做和重新观察。
- **连续表征**：同一对象在图片、图表、公式、代码和动画之间保持名称、颜色与空间关系对应。
- **变式迁移**：后续改变情境、条件或表征，复用之前学会的关系与操作。
- **隐形评价与适应**：尽量通过预测和操作判断理解，按实际学习状态调整提示，不为此强行接入 AI。
- **界面退后**：规则藏在可理解的场景、视觉暗示和即时反馈里，让学习者关注问题，不依赖长篇操作说明。

## 开场与节奏

新课程默认以“具体情境 → 疑问或冲突 → 学习动机”开始。可以采用历史故事、现实事件、生活情境或反直觉现象，不要求都使用故事。引子应在后续得到回应。

避免默认以定义、公式清单、知识目录或泛泛应用介绍开场；用户明确要求忠实转换原稿时，按其确认的范围保留原有顺序。

每页形成一个主要认知推进；合适时采用“尝试或预测 → 即时反馈 → 理解一个规律 → 再使用一次”。课程长度由知识完整性和学习节奏决定，不硬凑页数。

## 一个问题、一个视觉主角

先写清学生看完本页应能回答什么，再决定对象、文字、数据和交互。

- 只展示完成当前判断所需的信息。数值用于计算或比较时再呈现，不以数据量证明完整。
- 使用与教学目标一致的视觉编码，图形真正承担解释，避免文字旁放一张无关配图。
- 用少量大区域、明确空间关系和留白建立阅读顺序，避免等权重小卡片及 Dashboard 式堆叠。
- 不为了统一模板而统一所有构图；同页多个相关“块”仍放在一页，除非用户要求拆页。
- 动效用于对象对应、过程连续性和操作反馈，不堆装饰特效。
- 删除无助于判断的重复结论、说明、数值和控件，同时保留理解对象含义与计算关系所需的信息。

## 材料与表达

历史、人物和经典实验优先寻找真实图片、论文或档案，核实关键事实。难以获得适用素材时可教学重绘或生成插图，但不能冒充真实原图或实测数据；虚构情境、模拟数据和示意图须准确表达其性质。

素材来源、模型背景等必要资料可放讲稿或课程资料，不在学生页面堆放许可、访问日期等管理信息。

使用准确、清楚、自然的书面语言；标题直接提出问题、现象或结论。避免空泛口号、故作高深的术语和“这里先不讲什么”等元话语。用图和操作能说明的关系，不补成长段文字。
