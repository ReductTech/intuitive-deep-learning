# 本地 Agent 创作迁移实施计划

目标：保留网页创作，增加本地 Agent 新建、继续创作和私有共创。不增加 ZIP 接收或课程包存储。

架构：本地 Agent 使用课程专属凭证调用现有修订保存与构建。课程、工作区、预览、审核和发布复用 shuku_backend；不修改 idl_backend。
技术：React／TypeScript、Python、SQLAlchemy／MySQL。

1. 增加受限凭证和幂等修订记录及显式数据库升级；测试账号隔离、撤销、过期、删除清理。
2. 提供课程初始项目、草稿与基础版本读取；凭证只能保存指定课程的修订，不能审核、发布、建仓或操作其他账号。
3. 增加本地命令行助手：读取项目、保存源码、重试请求和查询构建结果。冲突时保留本地内容，不自动覆盖。
4. 创建页增加方式选择；我的课程与共创工作区提供本地继续修改；个人资料管理凭证。专属指令先准备再等待用户要求。
5. 复用现有构建、预览、审核、发布、组织建仓、私有分支机制，覆盖真实 React 互动、重复请求和草稿冲突。
6. 完成后端回归、前端模型测试、类型检查、构建和浏览器流程验证后，检查远程更新并提交到 IDL develop。

边界：接入现有 project.json／source.files 契约，保留原有源码与素材限制。模板中的 ZIP 上传说明不用于本接口。静态外部快照目前不支持现有修订编辑，应明确提示其 GitHub 流程，不能提供无效本地入口。真实 Web Agent 不在本次范围。
