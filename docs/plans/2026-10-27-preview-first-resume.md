# 继续创作优先预览编辑

问题：恢复课程时直接使用已保存的 guided.phase，未完成大纲会自动进入大纲讨论。

规则：首次新建保留交互引导；“我的课程 → 继续创作”统一使用原 CourseWorkspace 预览编辑布局。大纲和源码各自有可选入口。打开或切换视图不改写修订，不确认大纲、不生成或覆盖源码。

实现：ManagedEditor 分离当前视图与已保存的创作阶段；原 CourseWorkspace 接受自定义已保存页面渲染。React 页面通过受权限保护的原播放器，仅嵌入当前页，不重复嵌套播放器。预览缓存版本更新，已有课程修订和正式发布文件保持原样。

验证：覆盖未完成/已完成课程、首次创建、大纲往返和保存、源码保留、原预览编辑/讲稿入口与手机布局；运行类型检查、前端构建和原播放器相关后端测试。
