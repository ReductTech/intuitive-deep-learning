# 课程编辑入口统一

- 「继续创作」与「预览我的课程」统一进入 /my-courses/editor?course=…，兼容旧的课程预览链接。
- 继续使用 CourseWorkspace，默认进入编辑模式，共用页面导航、预览、对话窗口和交换布局。
- 管理操作放入「文件」菜单，保留课程大纲、源码、保存修订、审核和发布入口。
- 源码课程仍在隔离的已保存页面中展示，并用相同页面生成侧栏缩略预览。
- 指定 revision 的历史版本和审核预览保持原有含义，不跳转到最新课程编辑。
- 保留云端草稿、版本冲突检查、离开提醒与服务端权限验证。对话创作仍沿用当前能力，不新增 Web Agent。

验证：类型检查及生产构建；真实编译 React 页面与统一入口、布局切换、草稿/修订/刷新、大纲、演示和拒绝访问的浏览器回归；原播放器、本地 Agent、逐页创作与 PPT 导入回归。
