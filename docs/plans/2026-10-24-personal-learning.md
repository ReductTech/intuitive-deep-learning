# T06 个人学习

目标：收藏和续学记录绑定登录账号，换设备登录后可恢复。同一课程的不同正式版本分别保存进度；打开课程和共创仍默认最新版，继续学习使用上次版本。

1. 增加 favorites、learning_states 两张业务表，复用现有会话和数据库适配层；不读取浏览器收藏，不改 idl_backend。
2. 增加本人收藏、学习记录、版本上下文及进度接口。只接受公开正式版本或可信内置模块，服务端验证页面；用状态序号阻止旧设备覆盖新记录。
3. 首页接入账号收藏，增加学习记录及继续学习入口。统一学习入口保存页面、学习方式与完成页；正式版本保持原有冻结文件，支持手动切换历史版本。
4. 新播放器使用同源消息桥；旧的冻结播放器仅适配原有翻页按钮，保留教学展示方式，不能凭空获得新版播放器功能。私有预览不记为公开课程学习记录。
5. 验证账号隔离、重启保留、跨设备恢复、历史版本、并发冲突、下架恢复和永久清理；运行相关后端和浏览器验收、前端构建后推送 develop。
