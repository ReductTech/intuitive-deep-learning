# 本人课程删除

「我的课程」中，作者本人可点击「删除课程」，再次确认后删除。无需输入仓库名。管理员保留全站删除、下架和恢复入口；受托管理者没有删除他人课程的权限。

复用 POST /api/shuku/courses/{id}/remove（confirm: true）。服务端核验登录、同源、课程所有者或管理员身份。创建删除任务后课程退出列表；清理课程版本、上传文件及关联共创，按现有授权移除对应 GitHub 仓库。未获远程删除授权或其他清理失败时，保留任务供重试。

删除进度使用现有 /removals 与 /removals/{id}/retry。重复确认复用同一任务，重启后可继续。共享文件仍由引用检查保护。

验证：作者删除草稿及已发布课程、其他作者及受托管理者拒绝、简单确认与取消、失败重试、并发重复请求、删除后的记录和文件清理、管理员入口及移动端。
