# 标准课程导入实施计划

用户已确认路径 A，并于 2026-10-29 授权实施。GitHub 与 ZIP 共用校验、转换、预览、私有仓库初始化流程。导入不触发审核或公开发布。

1. 有界 ZIP / 固定 GitHub 提交读取；路径、类型、大小和链接校验；保留许可证；识别已实现的页面。
2. 复用任务表保存导入元数据和租约；源码、上传文件及二进制素材保存在本地文件桶；确认时原子创建课程、修订和后续任务。
3. 复用固定创作依赖构建双模式预览；初始化私有仓库真实源码；失败重试不重复创建课程或覆盖远程独立修改。
4. 创建页增加来源选择、检查结果、确认和任务恢复；已有编辑器、本地 Agent、审核发布继续共用课程修订。
5. 对素材授权、取消、过期和课程删除做引用保护及清理；补充精简测试，验证实际 ZIP 样本。
6. 检查远程最新状态，运行相关后端与前端验证，通过后提交并推送 IDL 独立仓库。

IDL 是独立 GitHub 仓库，本次不向 Demo / 产品仓库复制项目文件，不切换产品服务。
