# 渐进式课程大纲

沿用「选择方向 → 确认大纲 → 逐页制作」，本次重做确认大纲。

## 交互

1. 整体逻辑：默认折叠页面，先编辑讲述线索，看模块之间的关系。
2. 内容模块：选中模块，编辑标题和承接逻辑，调整顺序，添加模块或页面。
3. 每页内容：展开模块，选中一页编辑标题与核心内容，可跨模块移动、排序或删除。随时返回上一层，保留内容。

左侧为结构，右侧只编辑当前节点。大纲和思维导图共用数据。Markdown 使用 # 课程、## 模块、### 页面，支持编辑、导入和下载，点击「应用大纲」后更新项目。

## 保存与兼容

模块结构、讲述逻辑和当前步骤保存在首张页面的 outline.guided.plan，复用现有修订保存。移动或删除首张页面时，将元数据转存到新的首页。旧项目根据已有页面生成可编辑分组，不删除内容。逐页制作继续使用现有源码编译与保存流程。

## 边界与验证

Web Agent 尚未接入；初始分组是规则草案。大纲保留 1–100 页，最多 20 个模块。测试覆盖层级编辑、增删排序、Markdown 转换、首页删除后的保存，以及浏览器中的创建、修订保存、重新打开、继续制作和窄屏布局。
