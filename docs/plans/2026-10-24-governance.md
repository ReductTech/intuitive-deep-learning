# T06 课程治理

1. 管理员上下架；恢复仅恢复原状态，后台发版不能重新公开被下架课程。
2. 本人或管理员删除工作区；管理员永久删除课程及其工作区。确认只需一次按钮，无须输入名称。
3. 删除意图与持久任务同事务保存，冻结资源，取消排队构建，等待在途任务；失败保留进度，可重试同一任务。
4. 工作区私有修订物理删除；已合并贡献保留最小归属墓碑和评分，不保留可访问私有草稿。永久删除课程会清除关联业务记录，仅保留删除回执与审计。
5. 先记录候选文件，再删除引用，最后按哈希清理无引用对象。写引用持有共享事务锁，文件回收持有独占锁，防止并发复用文件被误删。分批检查点支持重启和重复执行。
6. 验证权限、上下架、关联清理、共享文件、并发引用、在途任务、故障与重试，并验证页面完整操作。本阶段不接 GitHub 远程删除（T07）。
