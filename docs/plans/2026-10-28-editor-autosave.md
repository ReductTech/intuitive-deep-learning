# 课程创作自动保存与离开提醒

- 停止编辑 1.5 秒后，将完整编辑项目保存到独立的私有草稿表。选择方向、大纲、源码及参考图均可恢复；未应用的 Markdown 也保留。
- 草稿保存不构建、不创建 GitHub 任务、不覆盖正式修订，不改变审核或发布状态。
- 保存采用修订号与草稿版本双重并发检查，防止其他窗口的修改被覆盖；失败显示重试入口。
- 仍有未保存内容时，站内链接离开需确认，刷新、关闭或跳转由浏览器显示原生提醒。保存成功后不拦截。
- “保存修订”串行等待当前草稿请求，成功后删除相应草稿；之后的新编辑继续自动保存。
- 新课程恢复已保存的引导阶段；已有修订默认进入预览编辑，保留可选的大纲入口。
