# 共创待审核统一列表

课程创作 → 共创待审核：所属课程、建议搜索，待审核／待合并／待发版／全部四个分类，默认待审核。

GET `/api/shuku/review-inbox` 聚合本地课程审核、共创建议和外部 PR。服务端按当前用户可管理课程限制范围，筛选及分页查询 PostgreSQL；同一只读快照中计算列表和角标，每页 20 条。

红色数字表示可由本人处理的事项：审核通过转待合并，合并构建完成后由正式课程的已批准修订计入待发版；发布成功退出待发版。本人不能审核的课程、自己的共创建议、正在合并、过期修订和删除中的资源不增加待处理数字。全部保留已发布、已退回等历史记录；已删除的个人工作区仍保留被接受的贡献历史。

本地与外部 PR 去重，发版以课程当前已批准修订为准，避免重复统计同一待发布内容。外部合并后仍沿用原有本地修订确认与审核要求。

正在执行的合并不增加待处理数字；合并构建失败、需要用户重试时重新计入待合并角标。

页面提供审核与合并详情入口，在当前列表弹窗发版。同步发版在完成远程任务后再次核验并完成本地发布；失败保留重试入口。列表每 20 秒及窗口获得焦点时刷新；搜索和课程筛选同时作用于列表与角标。

验证覆盖权限隔离、真实审核合并发布流转、下架及删除、历史、筛选参数、外部 PR；浏览器验证四分类、角标、筛选与搜索、页内发版、手机布局，并运行相关原有业务测试与生产构建。
