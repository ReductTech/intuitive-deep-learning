# 管理员数据管理

现有身份为 learner、creator、admin，由 PostgreSQL users.role 决定。客户端不提供角色切换或提权接口。

新增管理员专属 `/data` 入口，按课程管理、贡献数据、错误反馈、操作记录组织。GET `/api/shuku/admin/{courses|contributions|reports|records}?page=1` 每页最多 20 条，查询时重新验证服务器端角色，不读取全库快照或返回凭证、邮箱。

课程页复用上下架、恢复、永久删除及后台清理重试；贡献页查看建议与已接受贡献质量分排名；反馈页进入现有处理页；操作记录读取已有审计。排名仅统计已接受的贡献。

保留现有 GitHub 单课程状态与恢复操作。Demo 的组织仓库扫描收录、连接配置编辑、历史 GitHub 贡献采集及外部 Issue 上报维护尚未迁移，不模拟这些功能。这里的错误反馈为当前站内反馈记录。

验证：普通用户和创作者接口拒绝、匿名拒绝、页码校验及分页不重复、身份敏感信息排除、贡献排名；既有治理失败恢复与反馈处理；管理员 UI 入口、上下架恢复、删除确认、普通账号直达拒绝、手机端布局及前端构建。
