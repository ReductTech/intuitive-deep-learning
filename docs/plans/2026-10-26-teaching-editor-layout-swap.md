# 教学编辑布局交换

用户已确认：默认左侧页面缩略图、底部交互窗口；点击按钮后二者交换，中间课程预览保持为主区域。

- 在现有交互窗口右上角添加“交换布局”，仅交互窗口可用的编辑模式显示，按钮使用 aria-pressed 表示状态。
- 使用原组件和 CSS Grid 改变位置，不重挂载课程页面，不改变课程、聊天或输入状态。
- 左侧对话与输入继续上下排列；底部缩略图横向滚动，原翻页、大纲和页面属性继续使用。
- 退出编辑或进入演示恢复正常展示，再进入编辑保留本次会话的布局选择。
- 原生课程展示缓存版本递增，让已发布版本也获得此按钮；原源码、审核结果和版本号不改变。

验证：真实浏览器检查双向交换、键盘操作、输入和选页保留、原生页面 DOM 不重建、底部选页、演示及窄屏；冻结版本构建回归与课程创作回归。
