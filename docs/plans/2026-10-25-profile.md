# 个人信息中心

入口为顶部账号名称，地址 `/profile`，沿用 术库 的导航、颜色和响应式布局。

个人资料：姓名、简介、联系邮箱可修改；账号、角色和 UUID 只读。邮箱仅本人可查。保存使用当前会话和账号标识，拒绝修改他人资料或权限；资料写入 PostgreSQL，不使用浏览器存储。

存储：新增 `009_profiles.sql`，资料表关联用户 UUID；显示名称仍由 users 维护。GET／POST `/api/shuku/profile` 提供本人资料查询与更新，更新记录审计但不记录邮箱内容。

右侧提供个人课程、共创、收藏和学习记录入口。减论登录、GitHub 个人授权及 Agent 上传凭证尚未接入，明确展示状态，不模拟授权或凭证。

验证覆盖资料持久化、权限字段拒绝、账号隔离、账号切换保护、表单保存和取消、登录保护、窄屏布局，以及既有登录流程与构建。
