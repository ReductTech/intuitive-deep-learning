# 整站先登录

目标：访问首页、课程直链、收藏、创作和管理页面时，先完成会话验证；未登录时不挂载内部页面。复用现有 Demo 身份接口，不增加第二套账号体系。

1. App 最外层统一 LoginGate：检查中、登录、服务异常和已登录四种状态；保留当前路径、查询参数与锚点，登录后恢复原页面。
2. 页面收到会话 401 或重新聚焦发现过期时收起业务页面；首次验证的网络错误显示重试，不按游客放行。已验证会话的临时网络故障不丢弃当前编辑；账号变化重新挂载业务组件。
3. 浏览器验证匿名直接访问、无内容闪现、错误密码、登录恢复直链、退出、过期与接口故障；类型检查、构建和相关前端回归通过后推送。

这里调整的是站点交互入口，已有公开 API 的外部调用协议保持其原有权限规则。

验证：登录门禁浏览器验收、已登录 SceneDeck／课程长页与手机缩放、旧项目补齐新页、10 项创作模型测试及前端生产构建通过。页面检查脚本通过 SHUKU_E2E_PASSWORD 取得同站点测试会话。
