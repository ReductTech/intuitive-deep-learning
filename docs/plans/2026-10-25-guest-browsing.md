# 游客体验

登录页增加「游客体验」。游客可浏览公开课程、体验学习页面，也能查看课程创作、共创审核等功能入口。创建表单只供查看；审核列表展示四个阶段，不展示他人的审核记录。个人资料、消息、收藏与学习记录提示登录，不提供虚构账号或测试数据。

进入游客模式时 POST /api/shuku/auth/guest（同源 JSON 空对象），删除当前账号会话并清除 Cookie，不创建用户、游客 Token 或数据库记录。浏览状态仅保存在当前浏览器标签页的 sessionStorage，刷新和页面跳转保留。登录真实账号后清除游客状态。

sessionStorage 是界面标记，不能作为身份凭证。业务接口继续要求有效会话；游客直接调用创建课程、建立共创工作区、保存修订、提交审核、发版、个人资料等写接口均返回 401。前端 API 同时拦截游客写操作并打开登录页，页面预览不调用真实业务写接口。

LoginGate 对个人与创作路由显示 GuestFeaturePage；公开课程页面继续使用已有界面。导航保留原有风格，右上角显示「游客」「登录」。管理员数据不向游客公开。

验证：test_guest.py 覆盖清除旧会话、CSRF、拒绝伪造身份、匿名写操作和后续正常登录；check-shuku-guest.mjs 覆盖游客入口、只读表单、页面跳转与刷新、审核四阶段、个人数据隔离、手机排版及切换正式账号。相关登录回归及前端生产构建须通过。
