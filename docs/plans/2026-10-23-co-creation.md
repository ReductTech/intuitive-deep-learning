# T05 共创闭环实施

范围：复用现有编辑器、不可变修订和本地发布，新增私有共创工作区、教学内容差异、审核评分、合并与贡献溯源。GitHub 的远程事实核验由 T07 接入，不模拟成功。

1. 工作区固定选定正式版本；默认最新版。复制教学内容，不复制原作者的对话、设计参考图和撤销记录。
2. 修改保存使旧批准和评分失效；审核绑定修订和产物摘要；课程管理者审核，禁止自审自并。
3. 合并前核验基础正式版本与官方草稿均未变化，否则要求基于最新版重新共创，保留原工作区供参考。合并生成独立官方修订，通过持久构建任务核验后才成为待发布内容，发版继续单独确认。
4. 记录作者、审核者、合并者、分数与正式版本；排名只统计成功合并的当前有效分数。
5. 分别验证数据库约束、隔离、修改失效、冲突、重复合并、失败保留旧版，以及浏览器完整点击流程。
