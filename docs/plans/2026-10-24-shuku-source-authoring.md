# T03 React／TSX 课程创作实施计划

目标：新课程在网页中编辑多文件 React／TSX 源码，保存不可变修订，由 Worker 构建真实交互预览，经现有审核后发布。按用户要求，本次跳过 Web Agent。

实现位于 shuku_backend 与前端 shuku 模块，不修改 idl_backend。复用 MySQL 修订、任务、审核、发布及文件桶；源码文件纳入不可变清单。新增课程不要求预先登记为内置模块。

1. 源码契约：项目 source.files 为相对路径到文本的映射；React 页面使用 format=react、sourceEntry 指定默认导出的组件。校验文件数量、大小、路径和入口；禁止源码执行服务器命令、安装包或访问宿主文件。
2. 构建：虚拟文件系统解析源码与本地依赖；只复用服务器允许的前端包。生成固定版本的播放器、CSS 和资源。源码课程运行在不共享站点身份的浏览器沙箱；构建失败保留源码、诊断与旧正式版本。
3. 工作流：新建源码课程、保存、预览、审核发布；共创复制源码，差异显示源码变更，合并保持已审核产物。现有课程保持原路径。
4. 页面：源码文件列表、编辑、增加／删除文件、指定页面入口；保存后使用真实预览。明确标注 Web Agent 未接入。
5. 验证：源码构建与真实点击交互；越权、路径／宿主导入拦截、错误源码、审核发布、旧版不变；相关后端回归、类型检查及构建。使用独立测试数据库与临时文件，不切换运行服务。

范围：支持 React／TSX、JSX、JS、TS、CSS、JSON、文本 SVG 及受控前端依赖。不运行用户 package.json 脚本，不承诺任意 npm 工程零改动运行。Agent 服务及其真实联调保持未完成。

验收结果：源码专项 10 项、原新后端回归 86 项、原后端 79 项（4 项可选环境跳过）、前端模型 10 项、TypeScript 和生产构建通过。浏览器验证已覆盖完整源码创作发布链路与沙箱隔离。
