# 页面切换时登录页闪现修复

根因：页面跳转触发整页加载，LoginGate 初始会话查询尚未完成便渲染 PhoneLogin，导致有效会话也短暂出现登录标题和表单外壳。

调整：未验证身份时仅显示中性的状态提示，成功恢复直接进入原目标地址；明确收到 401 后才显示登录表单。初次验证网络失败提供重试，不展示登录表单，也不提前挂载业务页面。已验证用户在后台验证期间继续使用当前页面。

不缓存伪造的登录状态，不改变服务端会话、Cookie、权限或过期处理。

回归：延迟 auth/me 的课程创建、学习记录、收藏、个人信息与消息跳转；验证期间无登录表单、无受保护内容，恢复后保留目标路径和参数；网络失败重试及真实过期。另运行原登录门禁、手机号登录与品牌检查及前端构建。
