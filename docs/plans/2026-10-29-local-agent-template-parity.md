# Local Agent 工程对齐实施计划

**Goal:** 新课与私有共创使用 Demo 相同的完整 course-template 创作能力，并能保存回 IDL。

**Architecture:** 固定公共模板版本；只在本地克隆工程。共创按已选 nativeSnapshot 获取原模块及素材，不跟随官方最新版。客户端将标准 courses 工程转换为现有受限 React 源码修订；服务端复用审核发布和幂等冲突检查。无个人 Fork、ZIP 接收或账户密码授权。

**Tech Stack:** Python 标准库客户端、MySQL/SQLAlchemy、esbuild、现有模板 Vite 环境。

1. 为准备流程、标题/简介/分类、固定版本下载及本地文件保护编写回归测试。
2. 扩展项目快照，返回可信框架版本与原课程来源；分别生成新课、私有共创指令，首次只准备和等待。
3. 客户端 prepare 下载完整模板框架与固定原课程，保留旧 pull/push；标准 courses 工程可本地预览和同步修订。
4. 对齐 @shared/react、已安装的模板依赖、普通图片/字体和 Tailwind；保留文件路径、大小、依赖、浏览器沙箱限制。
5. 验证真实模板组件与原生课程源码构建；测试冲突、重试、权限、审核发布、旧客户端与前端回归。
6. 推送 GitHub，限资源部署后端及构建适配，不在服务器进行大型前端构建；验证后报告。
