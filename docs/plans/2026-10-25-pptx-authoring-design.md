# 以已有 PPT 开始交互式创作

- 创建表单增加可选 PPTX 上传，不增加模式选择。
- 读取每页文字和演讲者备注，保留顺序；随后仍经过选择方向、确认大纲、逐页制作。
- 逐页提供可折叠的原文与建议；支持返回修改并保存恢复。
- 首版只做 OOXML 文字解析和规则建议，Web Agent、图片 OCR、版式还原和动画转换不在本次范围。

## 存储与接口

POST /api/shuku/courses/import-presentation 使用会话鉴权与 multipart 上传。先校验和解析，再在同一事务中创建课程、私有初始修订及构建任务。原 PPTX 使用现有对象存储，并通过修订 files 清单中的 materials/original.pptx 关联；保存后续修订时继承该引用，不新增数据库表。

原文件不进入公开资源及 GitHub 导出。永久删除沿用既有引用锁及垃圾回收。限制单文件 100 MB、100 页、解压总量 512 MB；不执行宏、不跟随外链、不解压到磁盘。

## 验证

解析顺序、备注与图像页提示；损坏文件、旧 PPT、宏、XML 实体及不安全路径；HTTP 鉴权与同源；事务回滚、修订继承和原文件隔离；浏览器上传、大纲、建议、返回修改、保存恢复与移动端。

大文件通过 multipart 流分块写入临时文件；ZIP 从临时文件读取，原文件分块计算哈希后保存到对象存储。Nginx 上限为 101 MB，表单 file 字段最多 100 MB，避免整包在内存中重复复制。
