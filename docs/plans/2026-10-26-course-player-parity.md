# 本地预览与发布课程的展示一致性

课程放在 GitHub 不要求更换播放器。此前本地创作预览使用 CreatorWorkspace，发布构建使用精简 RuntimePlayer，因此缺少教学模式的缩略图导航。

## 共用部分

- NativeLesson：共用原生课程渲染和 guide/ppt 题目模式；文字页继续共用 TextPage。
- PageNavigator：共用本地工作台的幻灯片缩略图、大纲展开和页面选择。
- 固定画布继续使用共同的 useSceneScale；创作编辑工具与学习账号操作各自保留。

## 已发布版本兼容

学习页通过原有学习通信桥控制已发布播放器，不改写已发布课程文件。教学模式显示共用的幻灯片导航；自学模式收起导航。选择页面沿用现有进度、完成状态与版本，不跳转到最新版。没有通信桥的早期版本继续通过原有翻页控件适配。

学习上下文新增 page_details，仅包含页面 ID、标题、缩略图地址。缩略图必须存在于所选版本的文件清单中，并经过原有文件访问授权，不直接读取当前本地课程或任意远程 URL，不返回源码、备注或私人创作信息。

## 验证

覆盖缩略图加载、大纲展开、点击页面、模式切换、完成状态和历史版本续学、沙箱课程消息验证、手机布局，以及本地预览共用组件后的翻页。
