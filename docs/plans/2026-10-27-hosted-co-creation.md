# 无 GitHub 账号的托管共创迁移

目标：沿用 Demo 的组织 GitHub App，新课程创建私有仓库；共创使用 co-creation-workspaces 私有仓库中的 用户UUID/工作区UUID 分支。

1. 对齐 Demo 的共享仓库标识、分支归属和私有性检查。保留现有课程仓库自动创建功能。
2. 在独立 hosted_workspaces.py 模块实现保存修订后的持久化同步任务、差量 Git Blob 上传、检查点和失败恢复。复用现有 MySQL 任务表保存同步映射，不新增数据库表。
3. 接入共创保存、审核前同步依赖、授权后的状态查询和重试；不读取用户 GitHub 凭证。
4. 删除工作区或永久删除课程时仅清理对应分支，核验仓库 ID 和分支提交，保留共享仓库和其他人的分支。
5. 增加 MySQL/模拟 GitHub 验证：无绑定创建、隔离、重复执行、故障重试、增改删、权限和清理。验证网页私有预览及审核原流程。
6. 更新迁移进度，提交 GitHub，再部署独立服务并检查运行状态。真实联调使用专属测试分支；不修改已有课程分支。
