# T06 反馈与消息

学习正式版本 → 填写问题及可选位置 → 验证登录、课程和版本 → 同一事务保存反馈并通知课程所有者及有效管理者 → 点击消息自动已读 → 管理者更新处理状态 → 通知反馈者。

- 仅正式且可访问版本接受反馈；不接受客户端指定作者或课程归属。
- 提交使用请求 UUID 幂等；每账号每小时最多 10 条新反馈。管理状态采用版本号校验，重复处理不重复通知。
- 消息按接收人隔离，固定 20 条游标分页，未读计数独立于当前页；一键已读只修改本人现有消息。已读不代表反馈解决。
- 无有效课程管理者时通知有效平台管理员。管理员可处理反馈，但正常情况不把所有课程反馈广播给平台管理员。
- 课程永久删除时级联清理反馈和消息；下架仍保留已有反馈处理能力，不接收新反馈。GitHub Issue 创建由 T07 接入。
- 验证幂等与并发、接收者范围、状态冲突、权限隔离、分页、已读和一键已读，以及浏览器实际操作。
