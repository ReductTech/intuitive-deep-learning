# 课程管理折叠分组

使用原生 details/summary，统一三个分组：已上架（默认展开）、待收录、已删除（默认折叠）。待收录包含组织候选与未发布草稿；已删除区分可恢复的下架课程与永久删除记录/清理进度。已有审核、恢复和重试功能保留。分组在数据库查询时过滤，各自分页，避免只筛选当前页造成漏项。组织候选不再重复展示已收录或已移除仓库。

验证：管理员分组接口权限、状态过滤及分页测试；浏览器三组展开/折叠、审核收录、状态迁移、永久删除记录和移动端布局测试；TypeScript 检查与固定课程快照的生产构建。部署仅更新 Demo 的 Intuitive Deep Learning，保留原有课程资产和回退版本。
