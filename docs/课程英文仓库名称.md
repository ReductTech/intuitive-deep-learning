# 课程英文仓库名称

本地 Agent 根据实际课程内容建议英文名称，标准工程写入 `outlines.json.repositoryName`；直接提交项目的 Agent 写入 `project.json.repositoryName`。名称使用小写英文字母、数字和单个连字符，以字母开头，最长 80 字符，例如 `neural-network-basics`。首次准备环境时不猜名称。

私有课程仍先创建 `course-UUID` 仓库。审核通过后，发布窗口显示候选名，创作者可修改并检查是否被占用。发布任务再次检查，先改名并核验仓库 ID，再公开仓库、更新正式版本。重名不会覆盖其他仓库；发生冲突时换名重试。

已发布的独立课程可在「我的课程 → 同步与审核详情 → 修改仓库名称」改名。正在发布或改名时不接受另一改名操作。课程 UUID、GitHub 仓库 ID、修订与版本关联保持不变；网络中断后通过仓库 ID 恢复。不会批量改名已有课程，也不会修改共享官方课程库或共创工作区的仓库名称。

接口沿用现有登录、管理权限和同源保护：

| 接口 | 用途 |
| --- | --- |
| `GET /api/shuku/courses/:id/github/name` | 当前名称与 Agent 候选名 |
| `POST .../github/name/check`，`{name}` | 检查格式与占用；结果不等于预留名称 |
| `POST .../github/name`，`{name, expected_name}` | 已发布课程排队改名，防止旧页面覆盖新名称 |
| `POST .../publish`，增加 `repository_name` | 把创作者确认的名称固定到发布任务 |

名称保存在现有项目 JSON 和发布任务中，无数据库结构变更。GitHub App 需要已有的仓库管理权限；查询使用安装范围，避免仅有单仓库访问令牌无法发现其他私有仓库。GitHub 仍为最终占用裁决方。参见 [GitHub 仓库更新接口](https://docs.github.com/en/rest/repos/repos#update-a-repository)。
