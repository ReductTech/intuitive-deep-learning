# 远程课程目录与部署

## 数据流

`原仓库 develop → reduct-shuku/intuitive-deep-learning/main → 固定课程快照 → MySQL 目录 → 首页`

- 原仓库仍是课程编辑入口；独立仓库负责分发。
- `course-library.lock.json` 固定本次部署使用的提交。
- 后端启动时校验快照的 Git 状态、仓库、提交和课程标识，一次性登记 `shuku_library_courses`。请求页面时只查数据库，不请求 GitHub、不重新扫描目录。
- 首页统一调用 `GET /api/shuku/public/courses`。前端内置模块只负责渲染，不再决定线上展示哪些课程。只有专门的 `preview` 开发模式保留本地目录。
- 来源、标题、简介、分类、难度、封面和页数取自快照中的清单与 `outlines.json`。无分类时沿用课程 badge。

## 两类记录

| 类型 | 存储 | 学习入口 |
|---|---|---|
| 远程原生课程 | `shuku_library_courses`，主键为课程 UUID + 快照提交 | `module:<alias>`，由本次部署的课程组件渲染 |
| 用户在术库发布的课程 | 原有课程、修订、审核和发布表 | `course:<UUID>`，读取对应修订的构建文件 |

目录接口中，远程原生课程带 `kind: library`、`alias`、`module_id`、`source_commit`、`github_url`、`cover_url`、`page_count`；尚未登记为正式课程时，`version` 是提交号缩写；登记完成后包含 `course_id`、正式版本号和 `revision_id`。原有已发布课程字段保持兼容，仍包含 `revision_id`。

`GET /api/shuku/public/library/<alias>` 返回已登记的原生课程详情。未登记的本地模块不能仅凭前端路由出现在课程详情中。

使用 `python -m shuku_backend bootstrap-library --manager admin`，将当前快照登记为正式课程，由现有管理员账号创建和管理。首次构建验证完成后成为 `v1.0.0`；初始登记记为系统操作，不伪造人工审核或历史贡献。

`shuku_library_bindings` 记录源码模块与正式课程的唯一关联。首页不重复展示两个条目。重复登记不会覆盖课程内容、管理者或新版本；初始构建失败时重复命令会重试同一任务。下架与删除后不会被后续同步重新公开。

共创流程：选择已发布基础版本 → 本人私有草稿 → 保存、构建、本人预览 → 提交建议 → 管理员审核评分 → 合并已审核产物 → 发布更高版本号。未发布的修改不会改变公众看到的版本。反馈和贡献者记录沿用正式课程流程。

初始修订携带不可被浏览器更换的 `nativeSnapshot`。后续共创沿用该源码快照；部署上游新版时不能删除仍被修订引用的旧快照。已发布预览文件独立保存在对象目录，旧版可继续学习。

私有工作区当前使用术库的账号权限、数据库和文件对象存储，无需绑定个人 GitHub。独立课程分发仓库继续只读同步：本流程不会把网页共创写回该仓库，不自动创建该仓库的 PR 或分支；独立课程仓库的真实 GitHub 对接仍使用已有显式绑定流程。

## 更新与回退

1. 上游变动先由现有同步工作流写入独立仓库 main。
2. 部署人员执行 `npm run courses:fetch -- --latest`，获取固定快照并更新锁文件。
3. 使用 `IDL_COURSE_LIBRARY_ROOT=locked` 构建前端；后端 `SHUKU_COURSE_ROOT` 指向同一 `.course-library/<commit>` 目录。
4. 首次升级使用迁移账号执行 `python -m shuku_backend migrate`，增加目录表；运行账号不执行建表。
5. 部署前端并重启后端。执行上述 `bootstrap-library` 命令登记正式课程，后台按课程串行构建；构建完成即可共创。不得并行运行多个初始构建进程。

远程 main 更新不会直接切换线上课程；新增 TSX 必须先构建部署，防止目录先更新而页面尚不存在。同步失败会终止启动并保留上次部署，目录接口失败时前端明确显示错误，不偷偷回退本地列表。

旧快照的目录记录保留。回退时同时恢复前端、锁文件和 `SHUKU_COURSE_ROOT`；不删除用户业务数据。数据库升级是可重复的增量升级，保留原有基线校验，依次保留 `002_remote_course_catalog`，新增 `003_official_library_courses` 标记。

## 验证

- MySQL 测试覆盖目录登记、管理员归属、初始 v1.0.0、完整共创发版、私有隔离、旧快照固定、重复登记、失败重试和删除后不复活，以及显式迁移。
- 浏览器测试覆盖目录只展示 API 结果、空目录与接口故障不会回退本地课程、原生详情和原有发布版本/反馈流程。
- TypeScript、独立课程生产构建和课程导入来源检查均需通过。
