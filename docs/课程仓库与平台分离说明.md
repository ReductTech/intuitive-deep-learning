# 课程仓库与平台

- 编辑源：ReductTech/intuitive-deep-learning 的 develop。
- 课程分发：reduct-shuku/intuitive-deep-learning 的 main；原默认分支保存在 back。
- 自动同步：目标仓库 Actions 约每五分钟检查课程、素材与创作规范的变化，也可手动运行。仅同步新增和修改，不反向同步、不自动删除历史文件。

课程分发包含 modules、modules/shared、assets、creator-skill，以及课程清单、来源提交和文件校验记录。登录、业务数据库、审核发布及计算 API 继续由平台提供。目标独立修改会停止自动同步，避免覆盖。

## 平台读取

```sh
npm run courses:fetch
# 有意升级到分发 main 的最新版本，并更新锁文件：
npm run courses:fetch -- --latest
```

course-library.lock.json 固定分发提交；快照放在被 Git 忽略的 .course-library/<commit>/，更新时创建新目录，旧快照可用于回退。

前端构建设置 IDL_COURSE_LIBRARY_ROOT=locked；后端设置 SHUKU_COURSE_ROOT 为同一快照绝对路径。资产仍使用 UUID 地址，部署时将快照 assets 放到对应静态资源地址或 CDN。源码更新需要重新构建前端并部署，不能把 GitHub 上的 TSX 当作浏览器脚本直接执行。

未配置时仍兼容原 modules 目录；配置了快照但缺失或无效时会报错，不静默回退。切换失败可恢复上一静态发布和课程根目录，不迁移业务数据库。

## 验证

导出与冲突：python scripts/course-library-export.test.py。
固定版本拉取：node --test scripts/course-library-fetch.test.mjs。
独立构建：配置课程根目录后运行 node scripts/check-course-library-build.mjs（Node 22.18+），验证实际模块图没有回退原课程组件。
后端：backend/tests/shuku_backend/test_course_library.py，验证目录读取与原生课程预览构建。
