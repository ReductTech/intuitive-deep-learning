更新：2026-10-24。依据 [迁移任务](术库后端独立模块迁移任务.md)，实现位于 [shuku_backend](../backend/src/shuku_backend/README.md)。原 `backend/src/idl_backend/` 未改动，未切换 Demo 或产品服务。

## 已跑通的流程

**前端 Demo 登录 → 创建私有课程 → 现有编辑器保存修订 → 本人预览 → 提交审核 → 管理员退回／通过 → 作者正式发布 → 首页展示和版本播放。**

| 功能 | 实现与验证 |
| --- | --- |
| 登录与权限 | 固定测试账号、共用密码、持久会话、退出／过期／停用；真实前端连接新 API |
| 私有课程 | 创建、本人课程列表和权限隔离，预览及所有文件请求都校验身份 |
| 保存修订 | 项目和设计图保存到文件桶；不可变修订、对象清单及摘要入库；预期修订校验避免并发覆盖 |
| 版本预览 | Worker 构建固定 React／CSS 产物并冻结模块素材；文字页和原生课程页均验证，不用缩略图冒充完整课程 |
| 首次审核 | 绑定固定修订及产物摘要；意见、退回、修改重提、禁止自审；新修改撤销旧批准 |
| 本地正式发布 | 审核及完整性检查通过后，事务切换正式版本；递增版本号、重复请求、失败保留旧版；旧正式地址继续可读 |
| 基础运行 | 独立启动关闭、显式迁移和账号初始化、持久任务、检查点、租约及重启恢复；单向复用 IDL 客户端 |

## 共创闭环（T05 本地实现）

已发布课程点击“我想共创” → 选择正式版本（默认最新版）→ 私有工作区 → 编辑、保存与本人预览 → 填写说明提交 → 课程所有者／管理者查看差异、评分、通过或退回 → 合并 → 单独确认正式发版。

- 共创者可为学习者；不需要个人 GitHub。待审核列表按课程管理权限隔离，禁止自审、自评分和自合并。
- 新修改使旧批准和分数失效；合并复用审核时固定的运行产物，保留原正式版本，失败可重试。
- 贡献记录保存作者、审核者、合并者、质量分及进入的正式版本；排名只累计成功合并的有效分数。
- 官方已有待发布修改、基础版本变化或并发修改时拒绝覆盖；保留原工作区，基于最新正式版本重新共创。当前采用冲突阻止策略，尚无自动三方合并或重定位界面。
- 仅后端已发布课程提供共创入口；首页原有静态模块尚未自动登记为术库官方课程，需先通过创建与发布流程。

## 课程治理（T06 治理部分已实现）

- 管理员在“我的课程”下架／恢复课程。下架同时关闭公开目录、正式文件和共创入口；保留修订及版本，恢复原状态；发布操作不能覆盖下架决定。
- “我参与的共创”支持本人删除；平台管理员可永久删除课程及其全部工作区。只需按钮二次确认，不需要输入名称。
- 请求先保存回执、冻结写入并取消排队构建；持久 Worker 等待在途任务，分阶段删除关联记录和无引用文件。失败有进度和重试入口；重启可继续同一任务。
- 删除工作区后，私有修订及文件引用被移除，已合并贡献保留最小归属墓碑、署名和评分；官方正式内容继续可用。永久删除课程则删除课程、工作区、修订、审核、版本和贡献等关联业务记录，保留删除回执及审计。
- 文件清理只针对删除对象曾引用的哈希；复核所有存活修订的引用。与保存／构建使用匹配的共享与独占事务锁，保护并发复用的共享文件。
- 已接入 T07 远程私有化、恢复、仓库／审核分支删除；先核验远程结果，再清理本地记录。

## 反馈与消息（T06 站内部分已实现）

学习正式版本 → 反馈问题 → 通知课程所有者／管理者 → 从“我的消息”查看并自动已读 → 更新处理状态与说明 → 反馈者收到进度通知。

- 反馈绑定真实学习版本，支持原有正式历史版本；草稿或下架版本不能新建反馈。有效管理者均不可用时通知平台管理员。
- 提交幂等、限频，处理采用版本号防止并发覆盖；同一事务保存反馈与消息，不产生已接收但通知丢失的半完成结果。
- 消息按接收者隔离、游标分页、独立未读计数；点击已读和“一键已读”不改变反馈处理状态。顶栏提供未读提示。
- 下架保留反馈历史与处理，永久删除课程会级联清理反馈和消息。GitHub Issue 创建、超时查重及状态校准已接通；外部系统上报凭证仍属对外服务接入。

## 个人学习（T06 已实现）

- 探索课程与“我的收藏”使用本人账户的收藏；增加“学习记录”和“继续学习”。匿名用户可学习，登录后才保存，不自动导入浏览器中可能属于他人的旧收藏。
- favorites、learning_states 保存在 PostgreSQL 的 shuku_business 中；复用会话和 Store，替换数据库时只需适配 PersonalLearning 的数据访问，不依赖 localStorage。
- 正式课程按修订保存页码、完成页面、学习方式和更新时间。新发布版本不改变旧版记录；切换版本明确打开所选版本。进度采用状态序号，旧设备修改会提示刷新，避免覆盖新进度。
- 内置课程同样按账号保存，但属于未做正式发布版本管理的内置内容；正式历史版本能力用于审核发布的课程。已下架显示不可访问，恢复后可续学；永久删除级联清理相关收藏与进度。
- 新播放器通过同源消息桥保存状态；旧冻结播放器通过已有翻页控件恢复页码，只支持其原有教学展示方式。私有预览不写入个人学习记录。
- 实现和接口见 [个人学习接入](shuku-personal-learning.md)。
