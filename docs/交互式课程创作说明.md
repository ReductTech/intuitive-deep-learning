# 交互式课程创作

入口：课程创作 → 我要创建课程。填写基本信息后直接进入交互式创作。

1. 填写名称、简介和分类，也可上传已有 PPTX（20 MB 内、最多 100 页）。
2. 选择时长、风格和受众，得到可编辑的演示大纲。
3. 确认大纲，逐页选择图解优先、分步讲解或问题引入。
4. 不满意时补充文字和参考图，更新模板预览后重新选择。
5. 确认各页，保存修订、预览，再提交审核。

可通过「上一页」或顶部步骤返回，修改之前的时长、风格等选择。已编辑的大纲、页面方案和参考图会保留，不会因为返回而重新生成。

上传 PPTX 后，按原顺序读取每页文字与演讲者备注，直接作为可编辑大纲。逐页制作中的「原 PPT 与创作建议」可查看原文、备注及基于文字整理的建议。扫描图片中的文字、原版式和动画暂不转换；旧版 PPT 需另存为 PPTX。

原文件保存在私有对象存储，通过修订清单关联并随后续保存保留；不作为公开课件资源或 GitHub 导出内容。课程永久删除时沿用现有文件引用清理。创建与初始修订在同一数据库事务中完成，解析失败不会创建课程。

当前没有接入 Web Agent。大纲由规则生成，三个视觉方案是模板；图文补充会保存并用于模板预览，不会自动理解图文并生成任意新设计。页面显示「AI 生成待接入」。

已实现的模板结果会生成实际 React 源码，复用现有保存、构建、私有预览、审核和发布链路。创作意见保留在元数据中，不直接作为课程正文。

开发入口：src/creator/GuidedAuthoring.tsx；规则和源码生成：src/creator/guided.ts。
状态保存在 pages[].outline.guided，随修订保存；保存前请使用「保存修订」，重开已保存项目后继续制作。

验证：guided.test.mjs 覆盖大纲、逐页状态和源码编译；check-shuku-guided.mjs 验证选项、大纲编辑、图文补充、逐页确认、保存恢复和移动端。

上传接口：POST /api/shuku/courses/import-presentation，登录会话及同源校验，multipart/form-data 包含 metadata（课程信息 JSON）和 file（PPTX）。返回 course 与初始 revision；复用现有保存、构建、审核与发布接口。解析逻辑：backend/src/shuku_backend/presentations.py。
