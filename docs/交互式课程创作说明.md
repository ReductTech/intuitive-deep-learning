# 交互式课程创作

入口：课程创作 → 我要创建课程 → 交互式创作（默认）。

1. 填写名称、简介和分类。
2. 选择时长、风格和受众，得到可编辑的演示大纲。
3. 确认大纲，逐页选择图解优先、分步讲解或问题引入。
4. 不满意时补充文字和参考图，更新模板预览后重新选择。
5. 确认各页，保存修订、预览，再提交审核。

当前没有接入 Web Agent。大纲由规则生成，三个视觉方案是模板；图文补充会保存并用于模板预览，不会自动理解图文并生成任意新设计。页面显示「AI 生成待接入」。

已实现的模板结果会生成实际 React 源码，复用现有保存、构建、私有预览、审核和发布链路。创作意见保留在元数据中，不直接作为课程正文。

开发入口：src/creator/GuidedAuthoring.tsx；规则和源码生成：src/creator/guided.ts。
状态保存在 pages[].outline.guided，随修订保存；保存前请使用「保存修订」，重开已保存项目后继续制作。

验证：guided.test.mjs 覆盖大纲、逐页状态和源码编译；check-shuku-guided.mjs 验证选项、大纲编辑、图文补充、逐页确认、保存恢复和移动端。
