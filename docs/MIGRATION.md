## 新增的构建边界

构建入口通过每个模块的 `outlines.json` 查找自学与展示入口；共享组件随每门课程一起编译。动态资源使用模块 UUID，依赖到的其他 UUID 资源会一起写入产物。TSX/TS、source map 和工作缓存不作为静态产物发布。

源码开发与编译只发生在本课程仓库或执行主机。`npm run preview` 是普通静态服务器，仅服务 `dist`，不提供 Vite 源码编译、原站路由或原站数据库接口。

新产物契约：`course.json` 提供身份、标题、页面顺序、入口和封面；`artifact-manifest.json` 提供逐文件哈希和大小；整库 `catalog.json` 引用各门课程的固定产物。这是文件格式约定，不是已批准或已执行的数据库结构。

Creator Guide 使用的 Skill 文档保存为本课程素材中的固定教学参考快照，来源同一旧提交的 17 份 Markdown。构建时不查找外部 Skill 安装目录，也不复制 Skill 可执行脚本。
