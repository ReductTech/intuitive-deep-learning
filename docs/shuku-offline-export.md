# 当前模块离线交互网页

在本地术库的课程页面点击 **保存离线网页**，下载一个 `课程名-离线交互.html`。将该文件复制到其他电脑，使用 Chrome 或 Edge 双击打开即可，不需要启动 Vite 或连接服务器。编辑模式下也可从「文件 → 保存离线交互网页」导出。

导出范围为当前项目的页面顺序、内容以及该模块实际依赖的前端组件、图片、字体、音视频和数据。不会打包站点课程目录或其他课程播放器；内嵌示例引用的共享素材属于当前课程的依赖。相同素材按内容合并。动态编号图片按文件名模板收集，避免将整张素材目录装入文件。

离线文件保留真实 React 交互、翻页、讲稿和全屏。公式字体与本模块内嵌的自学示例也在文件内。云端配音及编辑入口不显示；内容安全策略禁止 HTTP 请求。服务器计算、在线 AI 与外站嵌入不属于离线能力。

本地 Vite 提供 `POST /api/shuku/offline-export`，使用已有页面构建器的 `--offline 1` 模式。它只接受同源请求，按模块 ID 在已配置的本地课程库查找源码，串行构建，流式传输 HTML，并在成功、失败或取消后清理临时文件。此接口不会改动课程源码或服务器修订。

验证：

```powershell
npm run typecheck
node scripts/check-shuku-offline.mjs <Playwright 的 index.mjs 绝对路径>
```

回归脚本将单个 HTML 移出构建目录，在断网浏览器里验证 React 状态、动态图片、图片去重、文字页面、翻页、内嵌课程及单模块范围。大型实课还应逐页检查，并操作实际教学交互。
